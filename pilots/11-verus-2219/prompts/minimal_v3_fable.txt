## The bug to fix
verus-lang/verus issue #2219: "ghost uses of never type invalidates borrowchecking"

Verus WRONGLY ACCEPTS (verifies) this program, which it should REJECT — `t` is a `tracked` (linear/affine) resource and is consumed twice:

```rust
proof fn test(nvr: !) { }
proof fn consume<T>(tracked t: T) { }
uninterp spec fn arbitrary<T>() -> T;

proof fn test2<T>(tracked t: T) {
    test(arbitrary());

    consume(t);
    consume(t);
}
```

The ghost use of the `!`-typed value causes Rust to treat the code after it as unreachable, so verus's borrow/linearity check for `tracked` resources is silently skipped and the double-consume slips through. A correct verifier must report an error here (e.g. "use of moved value: `t`").
