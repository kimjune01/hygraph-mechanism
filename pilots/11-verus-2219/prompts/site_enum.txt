## How to run verus on a single test program
verus verifies one `.rs` file at a time. From the repo root:

    cd /Users/junekim/Documents/verus-p11/source && env -u RUSTC -u RUSTUP_TOOLCHAIN PATH=/tmp/rustup-shims:$PATH \
      bash -c 'vargo build --release >/dev/null 2>&1 && ./target-verus/release/verus --crate-type=lib <path-to-file.rs>'

Interpreting output:
- a line like `verification results:: N verified, M errors` with `M > 0`, OR any `error[...]` / "use of moved value" => the program was REJECTED.
- `N verified, 0 errors` with no error lines => the program VERIFIED (was accepted).
Proof/spec code goes inside `verus! { ... }`; a file needs `fn main() {}`. Files using `!` need `#![allow(internal_features)] #![feature(never_type)]` at the top. IMPORTANT: that command REBUILDS the verifier (`vargo build --release`) before running, so it always reflects your latest source edits. A bare `./target-verus/release/verus` does NOT pick up edits — always use the command above.
