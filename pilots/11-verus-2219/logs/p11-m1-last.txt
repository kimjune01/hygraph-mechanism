Root cause / fix:
Verus represents erased ghost/spec values during lifetime checking with synthetic `erased_ghost_value` calls. When such a synthetic call has return type `!`, rustc’s MIR builder treated it like a real divergent call and removed the normal return edge in `lint_and_remove_uninhabited`, making following tracked-resource uses unreachable to borrow checking. The fix preserves the successor edge only for Verus’s synthetic `erased_ghost_value` calls, while leaving normal uninhabited-return calls unchanged.
