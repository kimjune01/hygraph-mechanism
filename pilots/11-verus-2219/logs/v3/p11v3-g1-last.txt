Root cause/fix:
Verus erases ghost/spec code into synthetic `erased_ghost_value` THIR/MIR placeholders. When the erased expression had Rust type `!`, MIR lowering treated the synthetic placeholder like a real diverging value, so rustc reachability/borrow checking skipped later tracked moves. The fix detects Verus-erased `!` placeholders during MIR lowering and treats them as non-diverging checking placeholders in operand, statement, and pattern-initializer contexts, while leaving real non-erased `!` divergence unchanged.
